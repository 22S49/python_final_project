# 도서 관리 시스템 (Python Final Project)

콘솔 기반 도서 관리 시스템입니다. (파이썬 객체지향 프로그래밍 학습용)
도서를 종이책/전자책으로 구분하여 등록하고, 전체 조회·검색·대여/반납 처리 기능을 포함합니다.
(※ 프로젝트 루트의 `main.py`를 직접 실행하는 방식만 사용합니다.)

- 개발 환경 : uv, Python 3.13+ (Python 표준 라이브러리만 사용)

---

## 프로젝트 구조

```
python_final_project/
├── src/python_final_project/   # 패키지 엔트리포인트 (본 프로젝트에서는 미사용)
├── models/                     # 도서 객체 관련 모듈 폴더
│   ├── base_book.py            # 상위 클래스 (Book)
│   └── specialized_books.py    # 하위 클래스 (PaperBook, EBook)
├── utils/                      # 공통 유틸리티 함수
│   └── helpers.py              # 값을 입력받는 함수 (get_string, get_int)
├── main.py                     # 프로그램 진입점, 메뉴 및 입출력 로직
├── pyproject.toml              # 가상환경 설정 파일
└── uv.lock                     # 가상환경 의존성 락 파일
```

### 클래스 구조

- `Book` : `title`, `author`, `isbn`, `status`(대여 상태)를 가지는 기본 클래스
  - `PaperBook(Book)` : `binding`(제본방식) 속성 추가
  - `EBook(Book)` : `format`(발행유형) 속성 추가

## 기능별 화면 설명

### 1. 도서 등록

도서명, 작가명, ISBN을 입력받고, 출판 형식(종이책/전자책)에 따라 `PaperBook` 또는 `EBook` 객체를 생성해 등록합니다.

**종이책 등록** — 출판형식 `1`을 선택하면 제본방식을 추가로 입력받습니다. (예: 양장본, 중철본 등)

![도서 등록 - 종이책](images/02_register_paperbook.png)

**전자책 등록** — 출판형식 `2`를 선택하면 발행유형을 추가로 입력받습니다. (예: EPUB, PDF 등)

![도서 등록 - 전자책](images/03_register_ebook.png)

**중복 ISBN 예외 처리** — 이미 등록된 ISBN을 입력하면 등록을 거부하고 메인 메뉴로 돌아갑니다.

![도서 등록 - 중복 ISBN](images/04_register_duplicate.png)

---

### 2. 전체 도서 조회

등록된 모든 도서의 정보(도서명, 작가명, ISBN, 대여상태, 종이책/전자책 고유 정보)를 순서대로 출력합니다. 등록된 도서가 없으면 안내 메시지를 출력합니다.

![전체 도서 조회](images/05_list_all.png)

---

### 3. 도서 검색

입력한 문자열이 도서명에 포함된 도서를 모두 찾아 상세 정보를 출력합니다(부분 일치 검색).

![도서 검색](images/06_search.png)

검색 결과가 없을 경우 안내 메시지를 출력합니다.

![도서 검색 - 결과 없음](images/07_search_empty.png)

---

### 4. 대여/반납 처리

ISBN으로 도서를 조회한 뒤 현재 대여 상태를 반전시켜 대여, 반납 처리를 한 번에 수행합니다. 존재하지 않는 ISBN을 입력하면 오류 메시지를 출력합니다.

![대여/반납 처리](images/08_rent_return.png)

---

### 5. 종료

`5`를 입력하면 프로그램을 종료합니다.

![종료](images/09_exit.png)

## 입력값 검증 및 예외 처리

`utils/helpers.py`의 `get_string`, `get_int` 함수로 입력 값에 대해 최소한의 유효성 검사를 수행합니다. 메뉴 선택 시에도 1~5 범위를 벗어나 값을 입력하면 안내 메시지를 출력하고 다시 메뉴를 보여줍니다. 

- `utils/helpers.py`의 값을 입력받는 함수
  - `get_string` : 공백만 입력하거나 빈 값을 입력하면 재입력을 요구
  - `get_int` : 숫자(정수)가 아닌 값을 입력하면 재입력을 요구

### 입력값 처리 경우의 수

**빈 값 입력** — 도서명 등 필수 항목에 아무것도 입력하지 않고 엔터를 치면 재입력을 요구합니다.

![예외 - 빈 값 입력](images/10_error_empty_input.png)

**숫자가 아닌 값 입력** — ISBN처럼 숫자를 입력받는 항목에 문자를 입력하면 재입력을 요구합니다.

![예외 - 숫자 아닌 값 입력](images/11_error_not_number.png)

**잘못된 출판형식 번호 입력** — 출판형식에 1, 2가 아닌 값을 입력하면 등록이 취소되고 메인 메뉴로 돌아갑니다. 앞서 입력했던 도서명·작가명·ISBN도 함께 초기화되어, 처음부터 다시 등록해야 합니다.

![예외 - 잘못된 출판형식](images/12_error_invalid_booktype.png)

**존재하지 않는 메뉴 번호 입력** — 메인 메뉴에서 1~5 범위 밖의 번호를 입력하면 안내 메시지만 출력하고 다시 메뉴를 보여줍니다.

![예외 - 잘못된 메뉴 번호](images/13_error_invalid_menu.png)

**존재하지 않는 ISBN으로 대여/반납 시도** — 등록되지 않은 ISBN을 입력하면 오류 메시지를 출력하고 시스템 메뉴로 돌아갑니다.

![예외 - 존재하지 않는 ISBN](images/14_error_isbn_not_found.png)
