# 📚 도서 관리 시스템 (Python Final Project)

파이썬 객체지향 프로그래밍(OOP)을 활용한 콘솔 기반 도서 관리 시스템입니다.
도서를 종이책/전자책으로 구분하여 등록하고, 전체 조회·검색·대여/반납 처리까지 지원합니다.

---

## 🛠 기술 스택

- Python 3.13+
- 표준 라이브러리만 사용 (외부 의존성 없음)
- 패키지/실행 환경 관리: [uv](https://docs.astral.sh/uv/)
- 핵심 개념: 클래스 상속(`super()`), 캡슐화(private 속성 `__`), 메서드 오버라이딩

---

## 📂 프로젝트 구조

```
python_final_project/
├── main.py                     # 프로그램 진입점, 메뉴 및 입출력 로직
├── models/
│   ├── base_book.py            # Book 기반 클래스 (공통 속성/메서드)
│   └── specialized_books.py    # PaperBook, EBook (Book 상속)
├── utils/
│   └── helpers.py              # 입력값 검증 헬퍼 함수 (get_string, get_int)
├── src/python_final_project/   # 패키지 엔트리포인트
└── pyproject.toml
```

### 클래스 구조

- `Book` : `title`, `author`, `isbn`, `status`(대여 상태)를 가지는 기본 클래스
  - `PaperBook(Book)` : `binding`(제본방식) 속성 추가
  - `EBook(Book)` : `format`(발행유형) 속성 추가

두 하위 클래스 모두 `display_info()`를 오버라이딩하여 `super().display_info()` 결과에 자신만의 정보를 덧붙여 출력합니다.

## ✨ 기능별 화면 설명

### 1. 도서 등록

도서명 · 작가명 · ISBN을 입력받고, 출판 형식(종이책/전자책)에 따라 `PaperBook` 또는 `EBook` 객체를 생성해 등록합니다.

**종이책 등록** — 출판형식 `1`을 선택하면 제본방식을 추가로 입력받습니다.

![도서 등록 - 종이책](images/02_register_paperbook.png)

**전자책 등록** — 출판형식 `2`를 선택하면 발행유형을 추가로 입력받습니다.

![도서 등록 - 전자책](images/03_register_ebook.png)

**중복 ISBN 예외 처리** — 이미 등록된 ISBN을 입력하면 등록을 거부하고 메인 메뉴로 돌아갑니다.

![도서 등록 - 중복 ISBN](images/04_register_duplicate.png)

---

### 2. 전체 도서 조회

등록된 모든 도서의 정보(도서명, 작가명, ISBN, 대여상태, 종이책/전자책 고유 정보)를 순서대로 출력합니다. 등록된 도서가 없으면 안내 메시지를 출력합니다.

![전체 도서 조회](images/05_list_all.png)

---

### 3. 도서 검색

입력한 문자열이 도서명에 포함된 도서를 모두 찾아 상세 정보를 출력합니다(부분 일치 검색).

![도서 검색](images/06_search.png)

검색 결과가 없을 경우 안내 메시지를 출력합니다.

![도서 검색 - 결과 없음](images/07_search_empty.png)

---

### 4. 대여/반납 처리

ISBN으로 도서를 조회한 뒤 현재 대여 상태를 반전시켜 대여 ↔ 반납 처리를 한 번에 수행합니다. 존재하지 않는 ISBN을 입력하면 오류 메시지를 출력합니다.

![대여/반납 처리](images/08_rent_return.png)

---

### 5. 종료

`5`를 입력하면 프로그램을 종료합니다.

![종료](images/09_exit.png)

---

## ⚠️ 입력값 검증

`utils/helpers.py`의 `get_string`, `get_int` 함수를 통해 모든 사용자 입력에 대해 유효성 검사를 수행합니다.

- `get_string` : 공백만 입력하거나 빈 값을 입력하면 재입력을 요구
- `get_int` : 숫자(정수)가 아닌 값을 입력하면 재입력을 요구

메뉴 번호 역시 1~5 범위를 벗어나면 안내 메시지를 출력하고 메인 메뉴로 돌아갑니다.

## 📝 알려진 이슈 / 개선 여지

- 대여/반납 처리(`4`) 완료 메시지가 처리 대상 도서명이 아닌, 직전에 `등록` 메뉴에서 사용된 지역 변수 `title`을 참조하고 있어 실제 도서명과 다르게 출력될 수 있습니다. `b_book.get_title()`로 대체하면 해결됩니다.
- 현재 데이터는 프로그램 종료 시 저장되지 않는 인메모리(dict) 구조로, 재실행 시 초기화됩니다. 파일/DB 저장 기능 추가 시 영속성을 확보할 수 있습니다.
